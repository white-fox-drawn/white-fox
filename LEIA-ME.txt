PORTFÓLIO — LIMPEZA CONSERVADORA DO CÓDIGO

COMO APLICAR
Substitua os arquivos do projeto pelos arquivos deste ZIP, respeitando a pasta
pages. Mantenha sua pasta assets no mesmo local. Os anexos recebidos continham
somente os cinco HTMLs, o CSS e o JavaScript; imagens, fontes e vídeos não estão
incluídos neste pacote.

- index.html
- style.css
- script.js

LIMPEZA REALIZADA
- Removidas regras CSS para section-button, photo-services e video-padrao,
  ausentes das páginas e dos elementos criados pelo JavaScript.
- Unificadas definições repetidas de header e button.
- Removidas declarações já cobertas pela cascata, preservando os tamanhos dos
  vídeos, as galerias mistas, os estados de interação e os ajustes responsivos.
- Removidas regras para vídeos dentro de video-grid, onde não há elementos
  video. As regras de image-link foram mantidas porque podem alcançar imagens
  na estrutura HTML existente.
- Retirados os filtros SVG sem uso das quatro páginas internas. O filtro usado
  pela personagem da página inicial foi preservado.
- Removido o visualizador oculto da página inicial, que não tem links de galeria
  para abri-lo. Os visualizadores das quatro páginas de projetos foram mantidos.
- Removida a classe projects-link, sem referências no CSS e no JavaScript.
- Removidos três fechamentos de section excedentes, sem alterar a árvore HTML
  resultante na comparação estática.
- Reutilizada a atualização da largura da tela e a seleção dos links de galeria
  no JavaScript. A navegação por coleção e a eliminação de mídias duplicadas no
  visualizador foram preservadas.
- Padronizada a indentação do cálculo de proporções e dos cartões de vídeo
  das galerias mistas; retirados espaços no fim das linhas.

PRESERVADO
Textos, links, endereços de mídias, dados de galeria, proporções, cores, efeitos,
carrosséis, menus, controles de vídeo e navegação por teclado. As alternativas
para JavaScript desativado e movimento reduzido também foram mantidas.

VALIDAÇÃO
- Sintaxe do JavaScript verificada com node --check.
- Estrutura HTML, textos e referências comparados com os cinco arquivos
  originais, descontando apenas os elementos sem uso removidos.
- Comparação estática da cascata CSS em 180 combinações: cinco páginas,
  estrutura original e estrutura com os elementos dos carrosséis, nove larguras
  de tela e os dois estados da preferência por movimento reduzido.
- Redução total de 7.230 bytes e 237 linhas nos sete arquivos de código.
- Não houve validação visual completa nem reprodução das mídias no navegador.
  A comparação estática não substitui essa verificação com os assets originais.

OBSERVAÇÕES SOBRE O CÓDIGO ORIGINAL
Para respeitar o pedido de preservar o resultado atual, esta revisão não muda
as tags <h> não padronizadas, os IDs honey-heading repetidos ou os caminhos de
mídia já existentes. Também há um fechamento </a sem o sinal > após o cartão
Efêmero em projeto1.html. Corrigir essa marcação pode mudar a árvore interpretada
pelo navegador, os títulos ou a organização dos carrosséis; exige uma revisão
separada com comparação visual. Nenhum conteúdo foi excluído por parecer
repetido: imagens e links iguais podem ter funções diferentes nas coleções.
